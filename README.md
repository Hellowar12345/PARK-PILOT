PARK-PILOT Demo — 一鍵啟動說明
====================================

■ 怎麼啟動（很簡單）
  1. 把整個「PARK-PILOT-demo」資料夾複製到電腦任一位置
     （路徑盡量別有奇怪符號，放桌面最保險）。
  2. 雙擊  start.bat
  3. 第一次啟動會自動安裝環境（uv + Python + 套件），約 3-5 分鐘，
     會跑一堆下載訊息，那是正常的，等就好。
  4. 等伺服器準備好，瀏覽器會「自動打開」 http://localhost:8000/pilot
     → 看到畫面就可以開始錄影了。
     （若沒自動打開，手動開瀏覽器貼上這個網址）

■ 要錄的頁面
  - http://localhost:8000/pilot     ← 主角：PARK-PILOT 代理人介面
  - http://localhost:8000/          ← 預測地圖（選目的地看附近路段預測）
  
■ 操作建議（pilot 頁）
  - 用「模擬模式」（預設就是）。
  - 目的地直接打「板橋車站」，半徑抓 0.5~0.6 km 效果好。
  - 送出後 agent 會自己：定位 → 查天氣 → 呼叫模型預測 → 用後悔值選位
    → 鎖定 → 監看；車位被佔時會「自動重新規劃」並通知。
  - 上方模型標籤顯示 gemini-3.1-flash-lite（代理人用 Gemini function-calling）。

■ 結束
  - 直接關閉那個黑色命令視窗，就會停止伺服器。

■ 環境需求
  - Windows 10 / 11，需要連網路（裝套件 + 呼叫 Gemini API）。
  - API 金鑰已經放在 .env 裡，不用另外設定。

■ 常見狀況
  - 防火牆跳出詢問 → 按「允許」。
  - 第一次啟動較久＝正在裝環境，屬正常；之後再開只要幾秒。
  - 若顯示 8000 埠被占用 → 先關掉占用的程式再開，或回報請我改埠號。
  - 看到 "Application startup complete" 就代表伺服器好了。
